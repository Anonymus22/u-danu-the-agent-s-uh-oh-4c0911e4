One word an agent says when it has no idea what to do: **recalculating**.

The GPS voice every lost driver knows — the machine's honest confession that
it has no clue where it is or where to go next, delivered while it stalls for
time. `main.ts` writes exactly that one word to `/output/entry.txt`.
